2003年生まれの自分が、これまで使ってきたPCのOSを振り返ってみる。

こうして並べると、Windows XPからWindows 11、Snow LeopardからmacOS Golden Gate、さらにUbuntuやRaspberry Pi OSまで、思った以上に多くのOSに触れてきた。

とはいえ、古いOSを収集していたわけではない。家のPC、中高の貸与PC、部室のiMac、大学の演習室、研究室のロボットなど、その時々の環境で自然に使ってきたものが多い。

使っていた時期が重なるものもあるので、Windows、Mac、大学・研究の環境に分けてまとめてみた。細かな機能の比較よりも、当時の思い出や個人的な印象が中心になる。

<p style="font-size:12px;color:#747b8c;line-height:1.8;">Windows XP・Vista・7、Snow Leopard・Yosemiteのスクリーンショットは、2026年9月に仮想マシンで起動して撮影したものです。</p>

<p style="font-size:12px;color:#747b8c;line-height:1.8;">見出し下には初回の一般向けリリースの名称・バージョンと公開年月を記載しています（世界向けの公開時期。自分が使い始めた時期とは異なります）。年月のリンクから公式情報を確認できます。</p>

## 家と学校で使ってきたWindows

### Windows Vista

<p class="os-release" style="font-size:12px;color:#747b8c;line-height:1.9;margin:-8px 0 22px;">一般公開 <a href="https://news.microsoft.com/speeches/bill-gates-united-kingdom-launch-of-windows-vista-and-2007-microsoft-office-system-at-the-british-library/" target="_blank" rel="noopener noreferrer" title="公式のリリース情報" style="color:inherit;text-decoration:underline;text-decoration-color:#c5c9d1;text-underline-offset:3px;"><time datetime="2007-01">2007年1月</time></a></p>

Vistaも、親が仕事で使っていたPCのお古で触れたOSだった。

世間ではかなり不評だったらしいが、自分は結構好きだった。

半透明のウィンドウや光沢のあるUIが、当時の自分にはかなり未来的に見えた。macOS TahoeのLiquid Glassにも、少し通じるものを感じる。

子どもだったので、性能や互換性の問題はよく分かっていなかった。とにかく見た目が好きなOSだった。

今見返すと、画面の右側に時計や写真などのウィジェットが並んでいるのもいい。当時からこういうものがデスクトップにあったのは、何気に先進的だった気がする。

### Windows 7

<p class="os-release" style="font-size:12px;color:#747b8c;line-height:1.9;margin:-8px 0 22px;">一般公開 <a href="https://news.microsoft.com/source/2009/10/22/microsoft-simplifies-the-pc-with-windows-7/" target="_blank" rel="noopener noreferrer" title="公式のリリース情報" style="color:inherit;text-decoration:underline;text-decoration-color:#c5c9d1;text-underline-offset:3px;"><time datetime="2009-10">2009年10月</time></a></p>

自分の小学生時代と世代的にいちばん重なるのは、Windows 7だ。XPやVistaには親のPCのお古で触れていたが、家のWindows 7にも思い出がある。

親がたまにやっていたソリティアも好きだったので、この画面を見ると懐かしくなる。

その後、中高の貸与PCでも6年間使っていた。家でも学校でも馴染みがあり、自分にとって一番安心感のあるWindowsだ。

ただ、学校の貸与PCではソリティアを含むゲーム類が除外されていて、一切遊べなかった。ゲームの思い出は、あくまで家のPCでの話だ。

Vistaのデザインを受け継ぎつつ、全体的に使いやすくなった、正統進化という印象だった。

学校のPCなのでアプリのインストールには制限があったが、なぜかLunascapeやCent Browserなど一部のブラウザは導入できた。そのあたりの試行錯誤も含め、中高時代の思い出がかなり詰まっている。

### Windows 8

<p class="os-release" style="font-size:12px;color:#747b8c;line-height:1.9;margin:-8px 0 22px;">一般公開 <a href="https://news.microsoft.com/en-hk/2012/10/26/20121026/" target="_blank" rel="noopener noreferrer" title="公式のリリース情報" style="color:inherit;text-decoration:underline;text-decoration-color:#c5c9d1;text-underline-offset:3px;"><time datetime="2012-10">2012年10月</time></a></p>

なんだったんだ、これは。

PCを使っているのに、突然タブレット向けの操作を求められているような違和感があった。

新しいことをしようとした意図は分かるが、歴代Windowsの中では一番苦手だった。

### Windows 8.1

<p class="os-release" style="font-size:12px;color:#747b8c;line-height:1.9;margin:-8px 0 22px;">一般公開 <a href="https://news.microsoft.com/source/2013/10/17/windows-8-1-is-available-now-2/" target="_blank" rel="noopener noreferrer" title="公式のリリース情報" style="color:inherit;text-decoration:underline;text-decoration-color:#c5c9d1;text-underline-offset:3px;"><time datetime="2013-10">2013年10月</time></a></p>

最初からこうしてほしかった。

Windows 8で感じていた不満が多少改善され、従来のWindowsに少し戻った印象だった。

### Windows 10

<p class="os-release" style="font-size:12px;color:#747b8c;line-height:1.9;margin:-8px 0 22px;">一般公開 <a href="https://news.microsoft.com/source/2015/07/29/windows-10-available-in-190-countries-as-a-free-upgrade/" target="_blank" rel="noopener noreferrer" title="公式のリリース情報" style="color:inherit;text-decoration:underline;text-decoration-color:#c5c9d1;text-underline-offset:3px;"><time datetime="2015-07">2015年7月</time></a></p>

最初は、Windows 7から強制的に更新させられるようなイメージがあり、あまり好きではなかった。

ただ、実際に使い始めると、なんだかんだで使いやすかった。派手な魅力はないが、長く使っていて安心感のあるOSだったと思う。

## 部室のiMacから、自分のMacBookへ

中高では映像部に所属していて、部室には動画編集用のiMacが置かれていた。自分が初めてMacに触れたのは、この部室だった。

中高の部室にあったiMacで使っていた、自分にとって最初のMac OS。

### Yosemite

<p class="os-release" style="font-size:12px;color:#747b8c;line-height:1.9;margin:-8px 0 22px;">OS X Yosemite 10.10 <span aria-hidden="true">·</span> 一般公開 <a href="https://www.apple.com/ca/newsroom/2014/10/16OS-X-Yosemite-Available-Today-as-a-Free-Upgrade/" target="_blank" rel="noopener noreferrer" title="公式のリリース情報" style="color:inherit;text-decoration:underline;text-decoration-color:#c5c9d1;text-underline-offset:3px;"><time datetime="2014-10">2014年10月</time></a></p>

話を中高の部活に戻すと、部室にあった新しめのiMacには、最初からYosemiteが入っていた。

このバージョンで、見た目が一気にモダンになった。というより、2015〜2025年頃によく見かけた、あのフラットなデザインになった、という方が自分の感覚には近い。

立体感の強いデザインから、平面的ですっきりした見た目に変わったのが印象的だった。個人的にもかなり好きなデザインだったし、今こうして見返しても、UIやアイコンは十分に通用すると思う。

当時も十分に丸っこいデザインだと思っていた。ただ、何でもかんでも角が取れて丸くなった今のデザインに見慣れてから見ると、アイコンにせよ、ウィンドウの端にせよ、Dockにせよ、意外と角ばっていたんだなと思う。

### El Capitan

<p class="os-release" style="font-size:12px;color:#747b8c;line-height:1.9;margin:-8px 0 22px;">OS X El Capitan 10.11 <span aria-hidden="true">·</span> 一般公開 <a href="https://www.apple.com/newsroom/2015/09/29OS-X-El-Capitan-Available-as-a-Free-Update-Tomorrow/" target="_blank" rel="noopener noreferrer" title="公式のリリース情報" style="color:inherit;text-decoration:underline;text-decoration-color:#c5c9d1;text-underline-offset:3px;"><time datetime="2015-09">2015年9月</time></a></p>

Yosemiteと見た目はそれほど変わらなかった印象。

ただ、名前が好きだった。歴代macOSの中でも特に響きが良い。

### High Sierra

<p class="os-release" style="font-size:12px;color:#747b8c;line-height:1.9;margin:-8px 0 22px;">macOS High Sierra 10.13 <span aria-hidden="true">·</span> 一般公開 <a href="https://www.apple.com/newsroom/2017/09/macos-high-sierra-now-available-as-a-free-update/" target="_blank" rel="noopener noreferrer" title="公式のリリース情報" style="color:inherit;text-decoration:underline;text-decoration-color:#c5c9d1;text-underline-offset:3px;"><time datetime="2017-09">2017年9月</time></a></p>

初めての自分専用のパソコンだったMacBookで使っていたmacOS。

部室のiMacでMac自体には触れていたが、日常的に使うようになったのはここからだった。

トラックパッドを使った操作や、複数のデスクトップを行き来する感覚が快適で、この頃からmacOSが好きになった。

その頃のスクリーンショットも見つかった。2017年10月、初めての自分のMacで開いていたのはTwitter。まだXではなくTwitterだし、上にメニューが並ぶUIも、今見るとずいぶん昔のものに感じる。OSだけでなく、開いているサイトにも時代が残っている。

### Mojave

## OSの記憶は、使っていた場所の記憶でもある

こうして振り返ると、自分にとってOSの記憶は、使っていた場所や時代の記憶と結びついている。

Windows XPなら小学生の頃の家のPC、Windows 7なら中高6年間の貸与PC。Snow Leopardなら部室のiMac、High Sierraなら初めての自分専用MacBookを思い出す。

Ubuntuは大学の演習室や研究室、Raspberry Pi OSは研究で使ったロボットと結びついている。

起動音や壁紙、ウィンドウの透明感、アプリのアイコンといった細かな要素も、当時を思い出すきっかけになる。

新しいOSに便利な機能が増えても、Windows XPの起動音やVistaの透明感、Windows 7の安心感は、今でも印象に残っている。

一方で、特に印象に残らないOSもある。それだけ自然に使えていたのだとしたら、それも悪くない。

思い出に残るOSも、意識せずに使えるOSも、その時々の自分を支えてくれていたのだと思う。
